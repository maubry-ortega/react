## React Todo List

Uno de mis primeros acercamientos al desarrollo de aplicaciones web con **React**, realizado hace aproximadamente dos años como parte de mi proceso de aprendizaje del framework.

La aplicación consiste en una **Todo List completa**, con funcionalidades para gestionar tareas y aplicar formato de **subrayado** al contenido. Este proyecto me permitió familiarizarme con conceptos fundamentales de React, como componentes, manejo de estado e interacción con el usuario.

**Tecnología principal:** React

**Repositorio:** [maubry-ortega/react](https://github.com/maubry-ortega/react)
